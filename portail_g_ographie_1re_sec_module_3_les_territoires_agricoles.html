Étape 0 : Télécharger le fichier autonome

Inclut la planification, les 50 questions, le quiz QCM et les flashcards.

1. Créer un dépôt (Repository) sur GitHub

Connectez-vous sur github.com, cliquez sur New repository (ex. : geo-sec1-territoires-agricoles), cochez Public puis cliquez sur Create repository.

2. Téléverser le fichier index.html

Cliquez sur uploading an existing file, glissez le fichier index.html téléchargé ci-dessus, puis cliquez sur Commit changes.

3. Activer GitHub Pages

Allez dans Settings > Pages, sous Branch sélectionnez main puis cliquez sur Save. Votre site sera en ligne en ~1 minute à l'adresse https://votre-pseudo.github.io/geo-sec1-territoires-agricoles/ à partager dans Google Classroom !
